# Launcher icon

`prince-launcher.png` is the original artwork generated with the built-in image-generation tool on 2026-10-22. It is a custom illustration for the local launcher, not a gameplay screenshot.

The app uses `Prince of Persia.app/Contents/Resources/PrinceOfPersia.icns`, with PNG representations from 16 to 1024 pixels. `CFBundleIconFile` in the app's Info.plist selects it. The Desktop shortcut points to that app.

The ICNS decoded successfully with macOS `iconutil`, the plist passed validation, and the Desktop launcher returned `SDLPoP v1.23`. Finder's displayed icon has not been visually verified from this session.
