Static browser game

Install Palace Run

Clone the project, serve the folder locally, and play in any modern browser. No package manager, build step, or external runtime is required.

1

Clone

git clone https://github.com/sergeville/prince-of-persia.git
cd prince-of-persia
2

Serve

python3 -m http.server 4173
3

Play

http://127.0.0.1:4173/

Notes

  • Opening index.html directly also works for a quick local test.
  • The game is a separate prototype and does not ship original Prince of Persia assets.
  • Use Enter or Space to start, arrow keys to move, and Esc to quit a run.
